# wisperbot_chat

`wisperbot_chat` is the planned Flutter SDK for WisperBot's customer-facing chat
experience. It will provide full-screen, launcher, embedded, modal, and headless
integration styles backed by the public visitor API.

The repository is currently in the specification/scaffold stage; the public Dart
API is not implemented yet. Start with:

- [Project goal](docs/PROJECT_GOAL.md)
- [Architecture](docs/ARCHITECTURE.md)
- [Design system](docs/DESIGN_SYSTEM.md)
- [API specification](docs/API.md)

The current Flutter application scaffold must be converted to a package before
implementation. Runnable sample code and platform projects will live in
`example/`.
